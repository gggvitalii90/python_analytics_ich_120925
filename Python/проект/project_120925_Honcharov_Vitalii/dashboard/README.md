# 📊 ПСК Ньютек — Финансовый дашборд

Интерактивный BI-дашборд для анализа финансовых операций компании.

## 🚀 Запуск

```bash
cd dashboard
npm install
npm run dev        # dev-сервер: http://localhost:5173
npm run build      # production-сборка → dist/
```

## 🧩 Возможности

| Функция | Описание |
|---|---|
| **KPI-карточки** | Приход, расход, баланс, кол-во транзакций, средний чек |
| **Денежный поток** | Месячный chart: приход/расход/накопленный баланс |
| **3D Pie — Типы операций** | Apache ECharts с псевдо-3D эффектом |
| **3D Pie — Банки** | Распределение оборота по банкам + наличный расчёт |
| **Проекты / Объекты** | Горизонтальные бары, top-15 |
| **Статьи бюджета** | Donut chart, top-10 + "Прочее" |
| **Тип оплаты / Ответственные** | Интерактивные чарты |
| **Сводная таблица** | Объект/Проект × Квартал/Месяц, экспорт CSV |
| **Детальная таблица** | Поиск, сортировка, пагинация, ссылки на документы |
| **Cross-filtering** | Клик по любому чарту фильтрует все остальные |
| **Выезжающий сайдбар** | Фильтры по всем измерениям, анимация 250ms |
| **Адаптивность** | Desktop, tablet, mobile |

## 🌐 Деплой на Beget

Загрузите содержимое папки `dist/` на хостинг Beget:

```bash
# После npm run build:
# 1. Открыть FTP-менеджер Beget (или FileZilla)
# 2. Подключиться: ftp.your-domain.ru / ваш логин / пароль
# 3. Загрузить всё из dashboard/dist/ → /public_html/ (или нужная папка)
# 4. Домен будет открывать index.html автоматически
```

### GitHub Actions (авто-деплой)

В секретах репозитория добавьте:
- `FTP_HOST` — хост FTP Beget
- `FTP_USER` — логин FTP
- `FTP_PASS` — пароль FTP

Раскомментируйте шаг деплоя в `.github/workflows/build.yml`.
