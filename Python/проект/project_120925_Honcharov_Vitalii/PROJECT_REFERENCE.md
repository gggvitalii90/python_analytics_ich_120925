# Справочник по проекту "Поиск фильмов"

## Файлы проекта

### config.py
**Назначение:** Загрузка конфигурации из `.env` файла и переменных окружения.

**Переменные:**
- `MYSQL_CONFIG` — словарь с параметрами подключения к MySQL (host, port, user, password, db)
- `MONGO_URI` — строка подключения к MongoDB
- `MONGO_DB` — название базы данных MongoDB
- `MONGO_COLLECTION` — название коллекции в MongoDB

**Функции:**
- `show_config()` — для разработчика: показывает какие хосты, БД, коллекции требуются для работы (пароли не показывает). Используется при проверке конфигурации и отладке проблем с подключением

---

### mysql_connector.py
**Назначение:** Класс для работы с MySQL базой данных sakila.

**Класс: MySQLConnector**

**Поля:**
- `conn` — объект соединения с MySQL

**Методы:**
- `__init__()` — инициализация, создает пустое поле conn
- `connect()` — подключается к MySQL, возвращает объект соединения
- `close()` — закрывает соединение с MySQL
- `get_genres()` — возвращает список всех жанров с диапазоном годов
- `search_by_keyword(keyword, limit, offset)` — ищет фильмы по ключевому слову с пагинацией
- `count_by_keyword(keyword)` — подсчитывает количество фильмов по ключевому слову
- `search_by_genre_and_year(category_name, year_from, year_to, limit, offset)` — ищет фильмы по жанру и диапазону годов
- `count_by_genre_and_year(category_name, year_from, year_to)` — подсчитывает количество фильмов по жанру и годам

---

### mongo_connector.py
**Назначение:** Единая точка подключения к MongoDB для всех компонентов.

**Класс: MongoConnector**

**Поля:**
- `client` — объект MongoClient
- `col` — ссылка на коллекцию MongoDB
- `connected` — флаг успешного подключения (True/False)

**Методы:**
- `__init__()` — инициализация, все поля = None/False
- `connect()` — подключается к MongoDB с коротким timeout (2 секунды), делает ping для проверки
- `close()` — закрывает соединение с MongoDB

**Важно:** Один MongoConnector используется для LogWriter и LogStats (не создаем два отдельных подключения).

---

### log_writer.py
**Назначение:** Записывает логи поисков в MongoDB.

**Класс: LogWriter**

**Поля:**
- `mongo_connector` — общий объект MongoConnector

**Свойства:**
- `connected` (property) — возвращает статус подключения из mongo_connector

**Методы:**
- `__init__(mongo_connector)` — принимает готовый MongoConnector
- `write_search_log(search_type, params, results_count)` — записывает один лог поиска в MongoDB с UTC timestamp

**Важно:** Если MongoDB недоступен или запись падает, логирование просто отключается, но поиск фильмов продолжает работать.

---

### log_stats.py
**Назначение:** Читает статистику поисков из MongoDB.

**Класс: LogStats**

**Поля:**
- `mongo_connector` — общий объект MongoConnector

**Методы:**
- `__init__(mongo_connector)` — принимает готовый MongoConnector
- `is_connected()` — проверяет, подключен ли MongoDB (используется в main.py перед входом в меню статистики)
- `get_top(n, search_type)` — возвращает TOP-N популярных запросов по типу поиска ('keyword' или 'genre_and_year')
- `get_recent(n)` — возвращает последние N уникальных поисков (любого типа)
- `close()` — пустая функция, закрытие делает MongoConnector

**Важно:** Использует MongoDB aggregation pipelines с $match, $group, $sort, $limit для построения статистики.

---

### formatter.py
**Назначение:** Форматирование вывода таблиц в консоль.

**Класс: Formatter**

**Методы (все static):**
- `format_search_params(search_type, params)` — преобразует параметры поиска в читаемую строку для таблицы
- `pretty_print_stats(headers, rows, empty_message)` — выводит статистическую таблицу (5 колонок, единое выравнивание)
- `pretty_print_results(results, start_index)` — выводит результаты поиска фильмов (5 колонок)

**Важно:** Если библиотека `tabulate` недоступна, использует простой текстовый вывод через `print`.

---

### main.py
**Назначение:** Главный файл программы с меню и логикой поиска.

**Функции:**
- `menu()` — выводит главное меню (поиск по ключевому слову, по жанру, статистика, выход)
- `menu_stats()` — выводит меню статистики (TOP-N по keyword, по genres-years, последние запросы, назад)
- `main()` — основная функция программы

**Логика main():**
1. Создает коннекторы: `MySQLConnector`, `MongoConnector`, `LogWriter`, `LogStats`
2. Подключается к MySQL (обязательно) и MongoDB (optional)
3. Запускает цикл главного меню
4. Обрабатывает выбор пользователя:
   - Пункт 1: поиск по ключевому слову с валидацией ввода и пагинацией
   - Пункт 2: поиск по жанру и годам с валидацией и пагинацией
   - Пункт 3: статистика (если MongoDB подключен)
   - Пункт 0: выход
5. Закрывает все соединения

**Важно:** Логирование в MongoDB обернуто в `try/except`, чтобы ошибки Mongo не ломали поиск в MySQL.

## Структура данных

### MySQL (sakila)
Используемые таблицы:
- `film` — список фильмов
- `category` — жанры
- `film_category` — связь фильмов с жанрами

### MongoDB
Коллекция с логами поисков, каждый документ:
```python
{
    'timestamp': datetime (UTC),
    'search_type': 'keyword' или 'genre_and_year',
    'params': {'keyword': '...'} или {'genre': '...', 'year_from': ..., 'year_to': ...},
    'results_count': количество найденных фильмов
}
```

## Валидация пользовательского ввода

### Главное меню
- Не пустое
- Только цифры
- Только 0, 1, 2, 3

### Ключевое слово
- Не пустое
- Максимум 100 символов
- Только буквы и пробелы
- Хотя бы одна буква
- Не кириллица (предупреждение)

### Номер жанра
- Только цифры
- Не длиннее 3 символов
- В диапазоне 1..количество_жанров

### Годы
- Только цифры
- Ровно 4 символа
- В диапазоне доступных годов для выбранного жанра
- year_from <= year_to

### TOP-N
- Только цифры
- Не длиннее 4 символов
- Диапазон 1..1000

### Пагинация
- Только 'y' или 'n'
- Цикл повторяется до валидного ввода
