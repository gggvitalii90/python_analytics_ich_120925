Как открывать материалы

Для большинства занятий выбирайте Colab. Binder полезен, когда нужен интерфейс JupyterLab, но первый запуск может быть долгим.

Colab Быстрее и привычнее для учеников. Хорошо, чтобы открыть файл, найти ячейку и скопировать код.
Binder Похож на Jupyter Notebook/JupyterLab. Может долго собирать окружение, особенно первый раз.
GitHub Самый стабильный просмотр файла без запуска кода. Удобно для чтения и ссылок.
Download Скачать конкретный notebook, если нужно работать локально.

Как работает поиск и помощник

Поиск сначала смотрит локальный справочник с ссылками на официальную документацию, затем показывает notebook, где запрос встречается в названии файла или ячейках.

Можно искать коротко: filter, col, dtype, int, hist. Для FAQ-запросов пишите как задачу: numpy to pandas, pandas to plotly, rolling plotly, mongo to df.
